## 🚨 **TROUBLESHOOTING**

### **Clients won't connect:**

-   [ ] Check firewall settings (allow Multiplicity)
-   [ ] Verify Primary IP address (ipconfig)
-   [ ] Ensure all PCs on same network
-   [ ] Restart Multiplicity on all PCs

### **Broadcast not working:**

-   [ ] Verify broadcast targets (all 3 clients checked)
-   [ ] Toggle broadcast mode (Ctrl+Shift+B)
-   [ ] Check for "BROADCAST" indicator
-   [ ] Restart Multiplicity

### **Input lag/delay:**

-   [ ] Check network latency (ping < 50ms)
-   [ ] Use wired Ethernet (not WiFi)
-   [ ] Disable encryption (if on LAN)
-   [ ] Lower remote display quality

### **MapleStory issues:**

-   [ ] Set to Windowed mode (not fullscreen)
-   [ ] Same resolution on all clients
-   [ ] Position windows at same location
-   [ ] Update graphics drivers
