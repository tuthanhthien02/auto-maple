# TeleportUp Routines

This folder contains routines specifically designed for testing and using the optimized TeleportUp command.

## Files:
- `teleport_up_test.csv` - Basic functionality test
- `teleport_up_timing_test.csv` - Timing verification (20ms)
- `teleport_up_anti_detect_test.csv` - Anti-detect pattern testing

## Usage:
1. Load any routine in MapleStory
2. Test TeleportUp functionality
3. Verify timing and anti-detect features
4. Report any issues

## Features:
- 20ms TeleportUp timing (vs 350ms original)
- Anti-detect protection
- Error handling
- Human-like patterns
