# Optimized Routines

This folder contains optimized routines using the new TeleportUp command with improved timing.

## Files:
- `recorded_routine_optimized.csv` - Balanced speed + safety
- `recorded_routine_advanced.csv` - Complex patterns for advanced maps
- `recorded_routine_pvp.csv` - Fast execution for PvP

## Features:
- 20ms TeleportUp timing
- Reduced wait times
- Added return sequences
- Anti-detect protection

## Recommendations:
- **Farming**: Use `recorded_routine_optimized.csv`
- **Complex Maps**: Use `recorded_routine_advanced.csv`
- **PvP**: Use `recorded_routine_pvp.csv`
