BUOC 1: CAI MINICONDA
------------------------------------------------------------
1. Tai Miniconda:
   https://docs.conda.io/en/latest/miniconda.html
   
2. Chon: Miniconda3 Windows 64-bit

3. Cai dat:
   - Double-click file .exe
   - QUAN TRONG: Tick [✓] "Add Miniconda3 to PATH"
   - Install
   
4. Restart terminal


BUOC 2: CHAY SCRIPT TU DONG
------------------------------------------------------------
Double-click file:

   setup_conda.bat

Hoac:
   
   setup_conda.bat

Doi 5-10 phut de script cai dat het packages.


BUOC 3: CHAY BOT
------------------------------------------------------------
Double-click file:

   run_bot_conda.bat

Hoac:

   1. Mo Anaconda Prompt
   2. Chay: conda activate automaple
   3. Chay: python main.py

============================================================
TROUBLESHOOTING
============================================================

Loi: "conda is not recognized"
  -> Dung Anaconda Prompt thay vi Command Prompt
  -> Hoac restart may sau khi cai Miniconda

Loi: Import error khi chay bot
  -> Chay: check_conda_env.bat
  -> Chay lai: setup_conda.bat

Loi khac:
  -> Xem file: CONDA_SETUP_GUIDE.md
