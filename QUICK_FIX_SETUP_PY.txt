============================================================
QUICK FIX: setup.py - No module named 'win32com'
============================================================

LOI:
   ModuleNotFoundError: No module named 'win32com'


GIAI PHAP NHANH (CHON 1):
============================================================

CAch 1: TU DONG (De nhat - Khuyien dung)
------------------------------------------------------------
   Double-click:  fix_pywin32_admin.bat
   
   Script se:
   - Tu dong xin quyen Administrator
   - Cai lai pywin32
   - Register COM DLLs
   - Test win32com
   
   Sau do chay:
   python setup.py


Cach 2: THU CONG (Neu script khong duoc)
------------------------------------------------------------
   1. Mo Anaconda Prompt AS ADMINISTRATOR
      (Right-click -> Run as Administrator)
   
   2. Chay tung lenh:
   
      conda activate automaple
      pip uninstall pywin32 -y
      pip install --upgrade pywin32
      python "%CONDA_PREFIX%\Scripts\pywin32_postinstall.py" -install
      python -c "import win32com.client; print('OK!')"
   
   3. Neu thay "OK!" -> Thanh cong!
   
   4. Chay:
      python setup.py


Cach 3: ALTERNATIVE (Khong can win32com)
------------------------------------------------------------
   Double-click:  create_shortcut_simple.bat
   
   Tao desktop shortcut MA KHONG CAN win32com!
